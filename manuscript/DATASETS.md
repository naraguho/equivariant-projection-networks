# Real manuscript datasets

The release tagged `data-v1` contains data generated by the exact electronic
calculations used for the manuscript.  The small files in `data/sample/` are
subsets of these same data, not synthetic replacements.

## Holstein force dataset

Physical parameters:

| parameter | value |
|---|---:|
| lattice | 30 x 30 |
| electron-phonon coupling | lambda = 2.0 |
| elastic coupling | kappa = 0.15 |
| damping | gamma = 0.64 |
| bath temperature | T = 0.1 |
| filling | 0.5 |
| time step | 0.02 |

Twenty independent trajectories contain 500 saved configurations each, at
steps 20, 40, ..., 10000.  The files are:

```text
input_Q_snapshots_steps20_to10000.npy      (10000, 900), float32
output_force_snapshots_steps20_to10000.npy (10000, 900), float32
metadata_run_step.npy                      (10000, 2), int32
```

The columns of `metadata_run_step.npy` are `(run, step)`.  Complete runs are
kept together:

```text
training:   1,2,3,4,5,6,7,9,11,12,13,14,17,18,19,20  (8000 configurations)
validation: 10,16                                      (1000 configurations)
test:       8,15                                       (1000 configurations)
```

## Falicov-Kimball free-energy dataset

The full CSV contains 96,900 local environments from 19 independent ED-kMC
runs (run 6 was excluded).  Each environment has 317 binary occupations inside
the circular cutoff `R_c=10`, four free-energy differences, and four masks for
legal moves.  The split is by complete trajectory:

```text
training trajectories:   1-8  (77,520 environments)
validation trajectories: 9-10 (19,380 environments)
```
